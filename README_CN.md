# 学习数据结构文件夹

本文件夹用于存放数据结构学习相关的代码和练习。

[English Version](README.md)

## 已添加的学习内容

### 线性表学习代码

已添加线性表相关的学习代码，包括但不限于：
- 顺序表（数组实现）
- 基本操作：初始化、插入、删除、查找、遍历
- 学生信息管理系统

### 二叉树学习代码

已添加二叉树相关的学习代码，包括但不限于：
- 二叉树的基本结构定义
- 二叉树的遍历算法（前序、中序、后序、层序）
- 二叉树的插入、删除操作
- 二叉搜索树的实现
